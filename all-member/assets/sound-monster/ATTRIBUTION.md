## 說明
- **未使用** AI 生圖、未自行繪製主角、未使用任何授權不明素材。
- **未使用像素風**：全部採 Kenney 向量卡通風（Platformer Art 系列），主角、場景、收集物畫風一致；UI 採同廠 Kenney UI Pack。
- 主角具備原生動畫幀（stand / walk1 / walk2 / jump / hurt / duck），遊戲內以這些幀組成 idle / 跑步 / 跳躍 / 受傷 動畫，並輔以縮放、旋轉、粒子強化表現。
- 部分「物理動作」音效（如終點派對煙火）另以 Web Audio 程序合成疊加，純為增色，非外部素材。
